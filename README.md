# EcoRota Paranaguá — Coleta Seletiva Comunitária

O **EcoRota Paranaguá** é uma solução mobile/PWA para a gestão e agendamento da coleta seletiva na Ilha dos Valadares (Paranaguá/PR).

## 🚀 Funcionalidades
- **Agendamento de Coleta:** Permite ao morador solicitar o recolhimento de materiais recicláveis.
- **Painel do Coletor:** Rota otimizada para os coletores com suporte a operação offline (IndexedDB).
- **Emissão de Protocolo:** Confirmação com identificação única para acompanhamento.

## ♿ Acessibilidade e RNF
- Em conformidade com o **WCAG AA** (alto contraste, indicação visual de foco e mensagens explicativas de erro).
- Suporte a funcionamento offline para áreas com sinal fraco de internet.

## 🛠️ Tecnologias Utilizadas
- HTML5, CSS3 e JavaScript Vanilla.
